# Edwin Aldrin — Data Analyst Portfolio

A responsive, Arcadia-inspired portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `PORTFOLIO/index.html` in a browser, or use VS Code Live Server.
3. Keep the `assets` folder beside `index.html`; asset paths are relative.

## Structure
- `index.html` — sections, content, accessible navigation and metadata
- `style.css` — responsive evergreen/luminous-green theme, cards and transitions
- `script.js` — mobile menu, scroll progress, reveal animations, certificate lightbox, copy-email action and back-to-top button
- `assets/images/` — portrait, project images, training certificate and supporting visuals
- `assets/icons/` — favicon, logo and skill icons
- `assets/resume/` — downloadable PDF resume

## Before publishing
- Verify that project GitHub links point to the exact repositories for each project. They currently lead to the GitHub profile because project-specific repository URLs were not supplied in the portfolio materials.
- The portfolio certificate section uses the supplied Besant Technologies Data Analyst Training certificate.
- Keep the job responsibilities consistent with your actual work and update them as your role evolves.
- Publish the complete `PORTFOLIO` folder to GitHub Pages or your chosen static hosting provider.

- `#resume` — resume summary card with View Resume and Download PDF actions.
